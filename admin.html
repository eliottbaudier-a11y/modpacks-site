générateur.

Remplis les infos du serveur, ajoute tes mods (colle des liens Modrinth), puis télécharge les deux fichiers à déposer dans le projet. Rien n'est envoyé nulle part — tout se passe sur ton appareil.

1 · Le serveur

L'identifiant est calculé automatiquement à partir du nom (il sert dans l'adresse : /modpacks/<id>).

auto — modifiable
2 · Les mods

Colle un lien Modrinth (ou plusieurs, séparés par un espace), choisis une catégorie, puis « Ajouter ». Le nom, l'icône, la description et le côté client/serveur se remplissent automatiquement.

Chaque mod ajouté est marqué Retenu par défaut (tu peux changer ça plus tard dans le fichier généré).

3 · Générer les fichiers

Télécharge les deux fichiers, dépose-les dans le projet, et le nouveau serveur apparaît avec exactement le même design.

Où déposer les fichiers

  1. Place <id>.js dans le dossier data/mods/ du projet.
  2. Ouvre data/modpacks.js et colle l'entrée copiée dans la liste window.MODPACKS = [ … ] (avant le crochet fermant, avec une virgule).
  3. Enregistre, republie sur Vercel. Aucune autre modification nécessaire.
4 · Modérer un pack en ligne

Ajoute ou retire des mods directement sur le site en ligne — publie un commit GitHub, visible en ligne après ~30-60s (redéploiement automatique). Protégé par mot de passe.
